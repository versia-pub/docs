The `User` entity represents an account on a Versia instance. Users can subscribe to other users, and post and interact with content through extensions such as [Social](/extensions/social). Users are identified by their `id` property, which is unique within the instance. Only the instance a User is on may send or serve that User.

## Subscriptions

Users accept [subscriptions](/entities/subscribe). A user's subscribers receive the entities that [Delivery](/federation#delivery) sends to them, such as changes to the user.

## Addresses

Users may be represented by a shorthand address, in the following format:

```
@username@instance
```

For example:

```
@alice@versia.example
```

This is similar to an email address or an ActivityPub address. Usernames are case-insensitive.

### Username

Username **MUST** be the user's `username`.

Usernames can be changed by the user, so an address may stop working. Use a [Reference](/entities#reference) for long-term references.

### Instance

Instance **MUST** be the [Domain](/entities#domain) that the user is on.

Contains metadata about a Versia instance, such as capabilities and endpoints. It is served by the instance it describes, has no `id`, and needs no [signature](/signatures), so that other instances can read the public key from it.

## Entity Definition

<Entity name="InstanceMetadata" type="InstanceMetadata" fetch={{ path: "/.versia/v0.7/instance", href: "/api/endpoints#instance-metadata" }} collectionsHref="/api/endpoints#instance-collections" idless>
    <div slot="collections">
        - `moderators`: [Collection](/structures/collection) of instance moderators ([Users](/entities/user)).
        - `admins`: [Collection](/structures/collection) of instance administrators ([Users](/entities/user)).
    </div>

    <Field name="name" type="string" required>
        Friendly name of the instance, for humans.
    </Field>
    <Field name="software" type="Software" required>
        Information about the software running the instance.

        <Field name="name" type="string" required>
            Name of the software.
        </Field>
        <Field name="version" type="string" required>
            Version of the software. Should use [SemVer](https://semver.org/).
        </Field>
    </Field>
    <Field name="compatibility" type="Compatibility" required>
        Information about the compatibility of the instance. Supported Versia Protocol versions are listed at the [well-known endpoint](/api/endpoints#well-known).

        <Field name="extensions" type="string[]" required>
            Supported extensions.
        </Field>
    </Field>
    <Field name="description" type="string">
        Long description of the instance, for humans. Should be around 100-200 words.
    </Field>
    <Field name="domain" type="Domain" required>
        Domain of the instance, used for federation.
    </Field>
    <Field name="public_key" type="PublicKey" required>
        Public key of the instance.

        <Field name="algorithm" type="string" required>
            Algorithm used for the public key. Can only be `ed25519` for now.
        </Field>
        <Field name="key" type="string" required>
            Instance public key, in [SPKI-encoded base64](/signatures#exporting-the-public-key).
        </Field>
    </Field>
    <Field name="logo" type="ContentFormat">
        Logo of the instance. **MUST** be an image format (`image/*`).
    </Field>
    <Field name="banner" type="ContentFormat">
        Banner of the instance. **MUST** be an image format (`image/*`).
    </Field>

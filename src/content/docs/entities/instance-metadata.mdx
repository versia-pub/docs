Contains metadata about a Versia instance, such as its capabilities and public key. It is served by the instance it describes, has no `id`, and needs no [signature](/signatures), so that other instances can read the public key from it.

## Definition

<Entity name="InstanceMetadata" type="InstanceMetadata" fetch={{ path: "/.versia/v0.7/instance", href: "/federation/endpoints#instance-metadata" }} collectionsHref="/federation/endpoints#instance-collections" idless checker>
    <div slot="collections">
        - `moderators`: [Collection](/structures/collection) of instance moderators ([Users](/entities/user)).
        - `admins`: [Collection](/structures/collection) of instance administrators ([Users](/entities/user)).
    </div>

    <Field name="name" type="string" required>
        Friendly name of the instance, for humans.
    </Field>
    <Field name="software" type="Software" required>
        Information about the software running the instance.

        <Field name="name" type="string" required>
            Name of the software.
        </Field>
        <Field name="version" type="string" required>
            Version of the software. **SHOULD** use [SemVer](https://semver.org/).
        </Field>
    </Field>
    <Field name="compatibility" type="Compatibility" required>
        Information about the compatibility of the instance. Supported Versia Protocol versions are listed at the [well-known endpoint](/federation/endpoints#well-known).

        <Field name="extensions" type="string[]" required>
            Supported extensions, each with its [version](/extensions#versions), such as `pub.versia:likes@1`. **MUST** include every extension that a listed one [requires](/extensions#requirements).
        </Field>
    </Field>
    <Field name="description" type="string">
        Long description of the instance, for humans.
    </Field>
    <Field name="domain" type="Domain" required>
        Domain of the instance, used for federation.
    </Field>
    <Field name="public_key" type="PublicKey" required>
        Public key of the instance.

        <Field name="algorithm" type="string" required>
            Algorithm used for the public key. **MUST** be `ed25519`.
        </Field>
        <Field name="key" type="string" required>
            Instance public key, in [SPKI-encoded base64](/signatures#exporting-the-public-key).
        </Field>
    </Field>
    <Field name="logo" type="Media">
        Logo of the instance. **MUST** be an image (`image/*`).
    </Field>
    <Field name="banner" type="Media">
        Banner of the instance. **MUST** be an image (`image/*`).
    </Field>

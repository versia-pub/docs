Collections are a way to represent paginated groups of entities. They are used everywhere lists of entities can be found, such as a user's outbox.

As Collections are independent and not part of a larger entity (like [ContentFormat](/structures/content-format)), responses carrying them **must** have a valid [Signature](/signatures).

A Collection can only hold entities [authored on the instance serving it](/federation/validation#authors-and-signers). To list entities from other instances, use a [URI Collection](#uri-collection).

## Entity Definition

<Fields name="Collection">
    <Field name="author" type="Reference">
        [Reference](/entities#reference) to the author of the collection. Usually the user who "owns" the collection.
    </Field>
    <Field name="total" type="number" required numberType="u64">
        Total number of entities in the collection, across all pages.
    </Field>
    <Field name="items" type="Entity[]" required>
        Collection contents. **Must** be an array of entities.
    </Field>

    <Example slot="example" unchecked>
    ```jsonc title="Example Collection"
    {
        "author": "versia.social:018ec082-0ae1-761c-b2c5-22275a611771",
        "total": 46,
        "items": [
            {
                "id": "456df8ed-daf1-4062-abab-491071c7b8dd",
                "type": "Note",
                "created_at": "2024-04-09T01:38:51.743Z",
                ...
                "content": {
                    "text/plain": {
                        "content": "Hello, world!"
                    }
                }
            }
        ]
    }
    ```
    </Example>
</Fields>

## URI Collection

URI Collections are identical to regular collections, but they contain only URIs instead of full entities. They are useful for cases when remote entities need to be included in a collection, as those are typically not stored in implementation databases.

<Fields name="URICollection">
    <Field name="author" type="Reference">
        [Reference](/entities#reference) to the author of the collection. Usually the user who owns the collection.
    </Field>
    <Field name="total" type="number" required numberType="u64">
        Total number of entities in the collection, across all pages.
    </Field>
    <Field name="items" type="Reference[]" required>
        Collection contents. **Must** be an array of [References](/entities#reference).
    </Field>

    <Example slot="example">
    ```jsonc title="Example URI Collection"
    {
        "author": "versia.social:018ec082-0ae1-761c-b2c5-22275a611771",
        "total": 46,
        "items": [
            "versia.social:f8b0d4b4-d354-4798-bbc5-c2ba8acabfe3",
            "social.bob.com:2B27E62snga763"
        ]
    }
    ```
    </Example>
</Fields>

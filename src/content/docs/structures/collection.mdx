Collections are a way to represent paginated groups of entities. They are used everywhere lists of entities can be found, such as a user's outbox.

A Collection can only hold entities [authored on the instance serving it](/validation#authors-and-signers). To list entities from other instances, use a [Reference Collection](#reference-collection).

## Definition

<Fields name="Collection">
    <Field name="total" type="number" required numberType="integer">
        Total number of entities in the collection that the requesting instance [may fetch](/federation#access), across all pages.
    </Field>
    <Field name="items" type="Entity[]" required>
        Collection contents. **MUST** be an array of entities.
    </Field>

    <Example slot="example" unchecked>
    ```jsonc title="Example Collection"
    {
        "total": 46,
        "items": [
            {
                "id": "456df8ed-daf1-4062-abab-491071c7b8dd",
                "type": "Note",
                "visibility": "public",
                "created_at": "2024-04-09T01:38:51Z",
                // ...
                "content": {
                    "text/plain": {
                        "content": "Hello, world!"
                    }
                }
            }
        ]
    }
    ```
    </Example>
</Fields>

## Reference Collection

Reference Collections are identical to regular Collections, but their `items` are [References](/entities#reference) instead of full entities. Use them when a collection can include entities from other instances.

Neither kind of collection carries a field saying which kind it is. The page that names a collection states its kind and the type of its items, and that is how to read its `items`.

<Fields name="ReferenceCollection">
    <Field name="total" type="number" required numberType="integer">
        Total number of entities in the collection that the requesting instance [may fetch](/federation#access), across all pages.
    </Field>
    <Field name="items" type="Reference[]" required>
        Collection contents. **MUST** be an array of [References](/entities#reference).
    </Field>

    <Example slot="example">
    ```jsonc title="Example Reference Collection"
    {
        "total": 46,
        "items": [
            "versia.example:f8b0d4b4-d354-4798-bbc5-c2ba8acabfe3",
            "bob.example:2B27E62snga763"
        ]
    }
    ```
    </Example>
</Fields>

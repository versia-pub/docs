Misconfigured or buggy instances often have trouble federating with others. This extension enables instances to send simple federation debug messages.

<Note>
    This extension is intended to help developers debug federation issues between instances. It is not intended for general-purpose messaging.
</Note>

The name of this extension is `pub.versia:instance_messaging`. Instances that support it list this name in `compatibility.extensions` of their [InstanceMetadata](/entities/instance-metadata).

## Purpose

Often, federation "fails silently" with no indication of what went wrong, as instances are incapable of communicating with each other outside of administrators manually checking logs.

For example, let's consider the following scenario:
1. `joe.social` and `jane.org` are two instances.
2. `joe.social` tries to fetch a user profile from `jane.org`, at `https://jane.org/.versia/v0.7/entities/User/nkGEd8eI98` for example.
3. `jane.org` responds with a [User](/entities/user) object with a missing or incorrect field, such as an improperly validated `username`.
4. `joe.social` is incapable of processing the response and silently fails to fetch the user profile.

In this scenario, `jane.org` has no way of knowing what went wrong, as `joe.social` does not provide any feedback.

## Sending Messages

To send a federation debug message, instances **SHOULD** make a `POST` request to the `/.versia/v0.7/extensions/pub.versia:instance_messaging/messaging` endpoint with a simple text body containing a helpful message.

The request has a `Content-Type` of `text/plain`, and needs no `Accept`. No signatures are required (either on the request or response), so that a message can still arrive when signing is what is broken. No response body is expected.

A receiver **MUST** treat the sender as unverified and the text as untrusted. It **MAY** answer `429 Too Many Requests`, or `413 Content Too Large` for a message it finds too long.

```text title="Helpful Message"
Validation failed for https://jane.org/.versia/v0.7/entities/User/nkGEd8eI98.
Reasons:
    - `username` must be alphanumeric. Found invalid character `@`.
```

Do not send useless messages, such as:

```text title="Unhelpful Message"
Federation failed.
```

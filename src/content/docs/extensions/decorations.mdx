The Decorations extension changes how a [User](/entities/user)'s profile looks: a header image, images drawn over or around their avatar, a background behind the profile, and a sound to play on it. Facts about the person, such as their pronouns, are in the [Profile extension](/extensions/profile).

## Definition

The fields go in the `pub.versia:decorations` key of a User's `extensions`.

<Fields name="Decorations" extension="pub.versia:decorations" on="User">
    <Field name="header" type="Media">
        A header image for the user's profile. Also known as a cover photo or a banner. **MUST** be an image (`image/*`).
    </Field>
    <Field name="avatar_overlays" type="Media[]">
        Overlay images to be placed on top of the user's avatar. Each **MUST** be an image (`image/*`), and can be animated, such as APNG, GIF or WebP.

        The first overlay in the array is the topmost overlay. The inner 80% of the overlay **SHOULD** cover the avatar, with the outer 20% extending beyond the avatar's bounds.
    </Field>
    <Field name="avatar_mask" type="Media">
        Mask image to be used to clip the user's avatar. **MUST** be an image (`image/*`) that is not animated.

        The avatar **SHOULD** be clipped to the mask's alpha channel. For example, a black square with rounded corners would clip the avatar to a rounded square.
    </Field>
    <Field name="background" type="Media">
        Background image to be displayed behind the user's profile. **MUST** be an image (`image/*`), and can be animated, such as APNG, GIF or WebP.
    </Field>
    <Field name="audio" type="Media">
        Audio file to be played when viewing the user's profile. **MUST** be audio (`audio/*`), such as `audio/mpeg`.

        Audio files can be used as a vector for abuse. Implementations **SHOULD** provide a way to disable audio playback.
    </Field>

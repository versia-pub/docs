Reporting can be used to report content to moderators or administrators of a remote instance for review.

When an instance receives a report, it **SHOULD** be reviewed by a moderator or administrator.

## Delivery

A Report is [delivered](/federation#delivery) to the instances the reporter's instance chooses.

## Entity Definition

<Entity name="Report" type="pub.versia:reports/Report" transient>
    <Field name="type" type="string" required>
        **MUST** be `pub.versia:reports/Report`.
    </Field>
    <Field name="author" type="Reference">
        [Reference](/entities#reference) to the reporting [User](/entities/user). Optional if the report is anonymous. A report without an `author` can only be attributed to the instance that signed it.
    </Field>
    <Field name="reported" type="ReportedEntity[]" required>
        The entities being reported.

        <Field name="type" type="string" required>
            Type of the entity being reported, such as `User` or `Note`.
        </Field>
        <Field name="reference" type="Reference" required>
            [Reference](/entities#reference) to the entity being reported.
        </Field>
    </Field>
    <Field name="tags" type="string[]" required>
        Report tags. Should be concise and clear, such as `spam`, `harassment`, `misinformation`, etc. Used for categorization.
    </Field>
    <Field name="comment" type="string">
        Additional comments about the report. Can be used to provide more context or details.
    </Field>

    <Inherits />

    <Example slot="example">
    ```jsonc title="Example Report"

            {

            {
                "type": "Note",
                "reference": "test.com:213d7c56-fb9b-4646-a4d2-7d70aa7d106a"
            }
        ],
        "tags": [
            "spam",
            "harassment"
        ],
        "comment": "This is spam."
    }
    ```
    </Example>
</Entity>

Polls (also known as surveys) are a useful tool for gathering feedback from followers and friends. The Polls Extension allows users to create and vote on polls.

## Definition

### Poll

Note that there is no `question` field: the question should be included in the `content` of the Note itself.

<Fields name="Polls" extension="pub.versia:polls" on="Note">
    <Field name="options" type="PollOption[]" required>
        Array of options for the poll. Each `PollOption` has:

        <Field name="content" type="ContentFormat" required>
            Text of the option. It can contain the same properties as a Note's `content` (e.g. [Custom Emojis](/extensions/custom-emojis) or HTML hyperlinks).
        </Field>
        <Field name="votes" type="number" required numberType="integer">
            Number of votes for this option.
        </Field>
    </Field>
    <Field name="multiple_choice" type="boolean" required>
        Whether the poll allows multiple votes to be cast for different options.
    </Field>
    <Field name="expires_at" type="RFC3339">
        RFC 3339 timestamp of when the poll ends and no more votes can be cast. If not present, the poll does not expire.
    </Field>

### Vote

A Vote is one user's vote for one option. On a poll with `multiple_choice`, a user sends one Vote for each option.

<Entity name="Vote" type="pub.versia:polls/Vote">
    <Field name="type" type="string" required>
        **MUST** be `pub.versia:polls/Vote`.
    </Field>
    <Field name="author" type="Reference" required>
        [Reference](/entities#reference) of the user who cast the vote.
    </Field>
    <Field name="target" type="Reference" required>
        [Reference](/entities#reference) to the note with poll that the user voted on.
    </Field>
    <Field name="option" type="number" required numberType="integer">
        Index of the option that the user voted for, in the `options` array of the poll.
    </Field>

    <Inherits />

    <Example slot="example">
    ```jsonc title="Example Vote"
    {
        "id": "6f27bc77-58ee-4c9b-b804-8cc1c1182fa9",
        "type": "pub.versia:polls/Vote", // [!code focus]
        "created_at": "2021-01-01T00:00:00.000Z",
        "author": "otherexample.org:6e0204a2-746c-4972-8602-c4f37fc63bbe", // [!code focus:3]
        "target": "example.com:f08a124e-fe90-439e-8be4-15a428a72a19",
        "option": 1
    }
    ```
    </Example>
</Entity>

## Behaviour

### Privacy

Individual votes are private. Clients **SHOULD NOT** display who voted, only the number of votes for each option and the total number of votes cast.

A poll's `options` hold numbers of votes, not voters, and a Vote can only be fetched by the instance of the poll's author.

### Voting

The instance of the poll's author **MUST NOT** count a Vote for a poll that has closed, for an `option` that does not exist, or for a second option on a poll without `multiple_choice`. Such a Vote is answered with `422 Unprocessable Entity` if it is checked before the [inbox answers](/federation/http#status-codes), and is otherwise dropped silently. A user's votes for the same option count once, whatever their `id`.

A user changes a vote by [sending the Vote again](/entities#changing-an-entity) with the same `id` and a new `option`, and withdraws it with a [Delete](/entities/delete). A change or Delete that arrives after the poll has closed leaves the numbers as they are.

A Vote's `target` **MUST NOT** change, and a receiver **MUST** discard a version that changes it. Voting in another poll takes a new Vote.

## Delivery and Access

A sender **MUST** [deliver](/federation#delivery) Votes to the author of the [Note](/entities/note).

Only the instance of the Note's author may [fetch](/federation#access) a Vote.

When a poll's votes change, its Note is [sent again](/entities#changing-an-entity), and **MUST** also be delivered to the users who voted.

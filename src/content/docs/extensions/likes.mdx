The Likes extension adds support for users to like and dislike notes.

## Definition

### Like

Likes are a way for users to show appreciation for a note.

## Behavior

Implementations **SHOULD** make sure that users cannot like and dislike the same note at the same time. If a user dislikes a note they have already liked, the like **SHOULD** be removed, and vice versa.

To undo a like or dislike, a [Delete](/entities/delete) entity **MUST** be used. The `deleted` property of the Delete entity **MUST** be a [Reference](/entities#reference) to the Like or Dislike entity to be removed.

## Delivery and Access

A sender **MUST** [deliver](/federation#delivery) Likes and Dislikes to the author of the [Note](/entities/note) and, if the Note is public, to the followers of the user who sent them.

Any instance that [may fetch](/federation#access) the Note, and the instance of the Note's author, may fetch a Like or Dislike.

## Collections

### User Collections

The Likes extension adds the following collections to the [User](/entities/user) entity:

- `pub.versia:likes/Likes`: [Reference Collection](/structures/collection#reference-collection) of all the notes the user has liked.
- `pub.versia:likes/Dislikes`: [Reference Collection](/structures/collection#reference-collection) of all the notes the user has disliked.

### Note Collections

The Likes extension adds the following collections to the [Note](/entities/note) entity:

- `pub.versia:likes/Likes`: [Reference Collection](/structures/collection#reference-collection) of all the likes the note has received.
- `pub.versia:likes/Dislikes`: [Reference Collection](/structures/collection#reference-collection) of all the dislikes the note has received.

## Interaction Types

This extension registers the following [interaction types](/extensions/interaction-controls#interaction-types):
- `pub.versia:likes/Like`, for liking a Note
- `pub.versia:likes/Dislike`, for disliking a Note
